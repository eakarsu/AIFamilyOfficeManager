# AI Family Office Manager

The supported backend boundary is `/api/governed-decisions`: tenant/entity-scoped proposals, provenance evidence, integer-minor-unit reconciliation, two distinct approvals, external result recording, and append-only audit history. There is no endpoint that can transfer funds.

Copy `.env.example` to `.env`. Migrate and bootstrap only through the explicit guarded backend scripts. `./start.sh` is nondestructive and legacy demo routes are disabled by default.

Custodian/bank/broker/accounting feeds, production key management, financial/tax/legal validation, and qualified professional review remain external blockers.
